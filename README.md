# DemoShopping Test Automation Framework

Test Automation Framework for UI and API testing of the DemoShopping application.

Application: [DemoShopping](https://intern.demoshopping.ru/)

## Tech Stack

### Current

- Java 25
- Maven
- Selenium WebDriver
- TestNG

### Planned

- Rest Assured
- Allure
- GitHub Actions
- Docker
- Jenkins

## Project Structure

The framework follows a layered structure separating test code, UI infrastructure, pages, components, actions, and configuration.

## Test Coverage

UI automation is implemented first. API and UI + API integration tests will be added later.

## Configuration

Test configuration is separated from the framework code and can be customized for different environments.

## How to Run

Run the tests using Maven Wrapper.

## Reports

Allure reporting will be added later.

## CI/CD

CI/CD integration with GitHub Actions and Jenkins will be added later.
